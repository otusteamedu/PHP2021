### Получение запросов из очереди RabbitMQ

Получить запросы из очереди `RabbitMQ` можно 2 способами:

1. Через веб интерфейс;
2. Через консольный скрипт на `PHP`.

Для этого было реализовано 2 класса:

1. `ConsumerWeb` - для работа в веб версии;
2. `ConsumerConsole` - для консольной версии.

Оба класса являются наследниками суперкласса `Consumer`.

#### Консольная версия

Для того чтобы получить запросы на банковскую выписку через консоль, нужно подключиться по `SSH`, к контейнеру с
веб-сервером и там запустить скрипт `consume.php`:

```shell
php consume.php
```

После чего скрипт начнёт работу и в консоль начнут выводиться сообщения, об успешной отправки уведомлений на почту
клиентов, с информацией о том что их запрос на банковскую выписку готов. Сообщения будут продолжать выводиться до тех
пор пока очередь `RabbitMQ`, не опустеет.
